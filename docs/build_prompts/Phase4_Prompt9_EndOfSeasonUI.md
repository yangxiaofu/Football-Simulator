## Goal

Add the player-facing display layer for everything Phase 4 has built:

1. **End-of-season summary screen** automatically displayed after each season completes — record, outcome, owner sentiment trajectory, hot seat going into next year, season narrative beat, records broken, peer rank, press conference summary
2. **Dynasty / HOF moment screens** — distinct dramatic event renders when the dynasty flag newly activates or HOF eligibility is first crossed for the player coach
3. **Career view CLI** (`view_career.py`) — full coach career: all tenures, championships, peer rank trajectory, multiplier history, records held
4. **Auto-display integration** in `run_season.py --complete-season` so the summary appears without the player needing to opt in

**Critical scope discipline**: terminal text only. No GUI, no web view, no animations. ANSI color is permitted but optional (must work without colors in plain terminals). The polished display is "well-organized clean prose with section headers" — not "rich terminal UI library."

```python
"""Phase 4 — Optional ANSI color formatting.

Use color() with a flag from CLI args. When use_color=False, returns
plain text. This keeps the rest of the rendering code clean.
"""
from src.utils.constants import (
    ANSI_RESET, ANSI_BOLD, ANSI_DIM, ANSI_CYAN, ANSI_YELLOW, ANSI_GREEN, ANSI_RED,
)


def color(text: str, code: str, use_color: bool) -> str:
    """Wrap text in ANSI color if use_color=True, otherwise return as-is."""
    if not use_color:
        return text
    return f"{code}{text}{ANSI_RESET}"


def bold(text, use_color=True):
    return color(text, ANSI_BOLD, use_color)


def dim(text, use_color=True):
    return color(text, ANSI_DIM, use_color)


def cyan(text, use_color=True):
    return color(text, ANSI_CYAN, use_color)


def yellow(text, use_color=True):
    return color(text, ANSI_YELLOW, use_color)


def green(text, use_color=True):
    return color(text, ANSI_GREEN, use_color)


def red(text, use_color=True):
    return color(text, ANSI_RED, use_color)
```

### Task 7 — CLI tool: view_career.py

Create `view_career.py` in the project root:

```python
"""Phase 4 — Coach career viewer.

Usage:
    python view_career.py saves/test.db                      # show player coach career
    python view_career.py saves/test.db --coach-id 7         # show specific coach (e.g., AI coach)
    python view_career.py saves/test.db --season 2026        # show season summary instead of career
    python view_career.py saves/test.db --no-color           # disable ANSI colors
"""
import argparse
import sqlite3
from src.db.connection import get_connection
from src.ui.career_view import render_career_view
from src.ui.season_summary import render_season_summary


def main():
    parser = argparse.ArgumentParser(description="Coach career and season summary viewer")
    parser.add_argument('db_path')
    parser.add_argument('--coach-id', type=int, default=None,
                        help='Coach ID; defaults to player coach')
    parser.add_argument('--season', type=int, default=None,
                        help='Show season summary for this year instead of full career')
    parser.add_argument('--no-color', action='store_true')

    args = parser.parse_args()
    conn = get_connection(args.db_path)
    use_color = not args.no_color

    coach_id = args.coach_id
    if coach_id is None:
        row = conn.execute("SELECT id FROM coach_career WHERE is_player=1").fetchone()
        if row is None:
            print("No player coach found in this save.")
            return
        coach_id = row[0]

    if args.season is not None:
        print(render_season_summary(conn, args.season, coach_id, use_color))
    else:
        print(render_career_view(conn, coach_id, use_color))


if __name__ == '__main__':
    main()
```
